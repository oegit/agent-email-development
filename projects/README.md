# projects/

Your email projects live here — one folder per project.

Ask the agent to scaffold a new one (see the [Quickstart](https://oegit.github.io/oe-docs/email-development-agent-guide.html#quickstart)). Each project gets its own `CLAUDE.md` (the brief), a `template.mjml`, and an `output/` folder — With Variables projects also get a `generate.js` and `package.json`.
